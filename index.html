스킬·버프 아이콘처럼 위치가 고정된 영역에 적합합니다. 원본 사이트의 전용 인식 모델이나 숫자 OCR을 사용하지 않습니다.

감지는 카드의 「영역 설정」에서 기준 이미지를 등록한 뒤 동작합니다. 화면 크기나 UI 위치를 바꾸면 다시 지정하세요.
GETTING STARTED

작은 준비, 편안한 사냥

01

원하는 타이머를 설정하세요

카드의 설정에서 지속 시간과 미리 알림, 반복 여부를 바꿀 수 있어요. 기본 시간은 예시이므로 실제 스킬과 버프에 맞춰 조정하세요.

02

시작하고, 알림을 확인하세요

개별 또는 전체 시작을 누르세요. 소리·음성은 환경 설정에서 조절할 수 있어요. 미니 타이머는 지원 브라우저에서 항상 위에 표시되고, 다른 브라우저에서는 작은 창으로 열립니다.

03

자동 감지가 필요하면 화면을 연결하세요

게임 창을 공유하고 카드의 영역 설정에서 아이콘 또는 경험치 영역을 드래그하세요. 등록한 이미지와의 일치·불일치, 화면 무변동을 감지합니다. 룬은 미니맵 내부 영역을 선택하면 보라색 후보를 실험적으로 탐색합니다. 실제 게임의 감지 정확도는 아직 검증하지 않았습니다.

화면은 이 브라우저 안에서만 처리됩니다. 공유 권한은 매번 직접 허용해야 합니다. 탭이 절전 상태이거나 컴퓨터가 잠들면 알림이 늦을 수 있어요. 재개 시 남은 시간은 실제 시각을 기준으로 보정합니다.

HTML 파일이나 설정 JSON을 공유해도 등록 음성은 포함되지 않습니다. 다른 기기에서는 음성 파일을 다시 등록해주세요.
